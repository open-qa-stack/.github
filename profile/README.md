# Open QA Stack

**Test campaigns for Playwright, drafted by agents and decided by people.**

Your team has applications to test and specifications nobody has time to turn into scripts. Open QA Stack puts agents on the job:
point it at your application and its documents and get Playwright tests proposed for review, then run them as campaigns you can plan, follow and close.
